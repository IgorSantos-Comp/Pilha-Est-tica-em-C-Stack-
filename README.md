# Pilha Estática em C (Stack)

> Apenas um conceito básico de como funciona uma estrutura de dados do tipo Pilha (LIFO - *Last In, First Out*) usando a linguagem C.

### 🛠️ O que tem no código?
Um menu interativo direto no terminal para testar as operações fundamentais de uma pilha:
- **Push:** Inserir elemento no topo.
- **Pop:** Remover o elemento do topo.
- **Peek:** Visualizar o topo sem remover.
- **Tamanho e Exibição:** Ver todos os itens armazenados.

### 🚀 Como testar
Se quiser compilar e rodar na sua máquina, use um compilador C (como o GCC):

```bash
gcc pilha.c -o pilha
./pilha  # Se estiver no Windows, digite: pilha.exe
